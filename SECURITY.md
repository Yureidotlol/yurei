# Security

Yurei is a research prototype.

- The contracts are **unaudited**.
- Nothing has been deployed to Robinhood Chain mainnet. Any "Yurei" contract you find on mainnet
  that is not listed in this repository's `results/` with its receipt is not ours.
- Do not put real funds behind these contracts.

If you find a vulnerability, please do not open a public issue. Contact the maintainers privately
via the X account linked from the site, with a description and, if possible, a failing test.
Known limitations are listed in [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md).
